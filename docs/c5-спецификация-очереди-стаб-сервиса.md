# Спецификация: стаб-сервис очередей

## 1. Назначение

Документ описывает очередь задач стаб-сервиса: приём сообщений, повторные попытки и наблюдаемость.

## 2. Поведение очереди

Сервис принимает задания через HTTP и обрабатывает их в порядке поступления. Каждый ответ содержит идентификатор задания и статус.

## 3. Повторные попытки

Неудачные задания повторяются с фиксированным интервалом, максимум три попытки, после чего задание помечается отказавшим и попадает в очередь недоставленных сообщений.

## 4. Наблюдаемость

Сервис публикует счётчики обработанных и отказавших заданий в endpoint /metrics.
